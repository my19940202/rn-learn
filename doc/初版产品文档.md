**✅ 产品功能 PRD 总结（精简版）**

**产品名称建议**：**AI Link**

### 1. 产品定位与目标
- **核心目的**：作为你**线下分享获客和变现的工具**，为参与分享会的用户提供一个**便捷的海外大模型统一入口**。
- **分发方式**：不正式上架应用商店，由你**线下提供装机服务**（帮用户安装 APK / TestFlight 内测版）。
- **核心价值**：让用户在一款 App 内快速切换使用 ChatGPT、Gemini、Claude、Grok 等海外主流模型，解决国内访问痛点。
- **商业模式**：通过分享会引流 → 装机服务 → 会员付费（额度、专属支持、更高用量）。

**目标用户**：参加你线下分享的技术人、职场人、企业用户，对 AI 提效有需求，但访问海外模型不便。

### 2. 核心功能列表（MVP 阶段）

#### **1. 用户账户体系（必须）**
- 注册 / 登录（手机号 + 验证码优先，支持微信一键登录）
- 账号与设备绑定（防止多人共用）
- 个人中心：用量统计、会员到期时间、模型使用记录

#### **2. 对话核心功能**
- **聊天界面**：
  - 新建对话 / 对话列表
  - 支持**多轮对话**上下文
- **输入方式**：
  - 文字输入（支持 Markdown 格式）
  - **语音输入**（集成 Minimax 语音转文字服务）
- **模型切换**：
  - 首页或对话内明显的位置切换模型（ChatGPT / Gemini / Claude / Grok 等）
  - 每个模型显示当前可用状态和大概延迟
- **输出特性**：
  - **流式输出（Streaming）**：实时显示回复
  - **Markdown 渲染**：支持标题、代码块、表格、列表等
  - 支持复制、重新生成、点赞/点踩等基础操作

#### **3. 对话存储**
- **本地存储**（推荐优先）：
  - 使用 Realm / SQLite / AsyncStorage
  - 优点：离线可看历史、无需服务器成本
- **可选云端同步**（会员功能）：
  - 用户可选择把对话备份到你的服务器
  - 支持多设备同步（手机换机后仍能看到历史）

#### **4. 会员与用量体系**
- 免费用户：每日/每月 token 限制
- 付费会员：更高额度、无限对话、优先队列、专属模型等
- 用量展示：当前剩余 token / 额度

#### **5. 其他辅助功能**
- 设置页面：清除缓存、切换后端节点、隐私协议
- 免责声明弹窗（每次打开或切换模型时提醒）
- 简单引导页（首次打开展示如何切换模型）

### 3. 用户主要流程

1. **安装激活** → 你线下帮装 App → 打开后引导注册/登录
2. **首页** → 看到推荐模型卡片 → 点击进入聊天
3. **聊天页** → 切换模型 → 输入文字/语音 → 流式接收回复
4. **历史记录** → 查看/删除过往对话
5. **个人中心** → 查看会员状态、充值/续费

### 4. 非功能性需求

- **性能**：启动快、流式输出顺畅、支持弱网环境（加 loading + 重试机制）
- **安全性**：API Key 全部放在你的 Cloudflare 后端，用户端不暴露
- **合规**：App 内显著展示免责声明，不做公开宣传；仅限线下小范围分发
- **技术栈**：
  - React Native + Expo
  - 样式：NativeWind + Gluestack UI / Tamagui
  - 状态管理：Zustand
  - 网络：fetch + ReadableStream 处理 streaming

### 5. 后续可扩展功能（MVP 之后）
- 语音对话模式（语音输入 + 语音输出）
- 图片理解 / 多模态
- 对话分享功能
- 企业版定制
- 小程序版本（作为补充入口）

---

**当前 MVP 建议优先级**：
**必须**：账户体系 + 聊天界面 + 模型切换 + 流式输出 + Markdown + 本地存储 + 语音输入
**建议**：简单会员额度控制
**后期**：云端同步 + 更多模型
